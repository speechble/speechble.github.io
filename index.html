개인정보처리방침

개인정보처리자 장민석(이하 “처리자”)은 Speechble을 이용하는 분의 정보를 소중히 다루며, 다음과 같이 개인정보처리방침을 공개합니다.

1. 처리하는 정보와 이용 목적

  • 마이크 입력: 사용자가 낭독을 시작했을 때 성경 낭독 여부를 확인하기 위해 실시간으로 처리합니다. 음성 인식은 기기 안에서 이루어지며, 원본 음성과 전체 음성 인식 문장은 저장하거나 기기 밖으로 전송하지 않습니다. 사용자의 음성을 음성 모델의 학습이나 개선에 사용하지 않습니다.
  • 통독 기록: 읽은 책·장·절, 통독 회차, 낭독 시간, 예상 시간, 완료 여부와 시각, 이어 읽기 위치 및 낭독 시도 횟수를 기기 안에 저장합니다. 통독 진도 표시, 이어 읽기 및 완료 판정에만 사용합니다.
  • 앱 설정: 선택한 번역본, 낭독 방식, 자동 스크롤 속도 등 사용자가 정한 설정을 기기 안에 저장합니다.
  • 사용자가 넣은 번역본: 번역본 이름·언어와 성경 본문을 기기 안에 저장하여 본문 열람, 검색 및 낭독 확인에 사용합니다.
  • 기술 정보: 앱이 비정상적으로 종료된 원인을 확인하기 위해 Android가 제공하는 종료 시각·사유와 메모리 수치를 기기 안에서 확인합니다. 낭독 내용, 음성 또는 인식 문장은 포함하지 않습니다.

현재 앱은 광고, 맞춤형 광고, 이용자 추적 또는 외부 분석 기능을 사용하지 않습니다. 앱에는 인터넷 권한이 없으며 위 정보를 기기 밖으로 전송하지 않습니다.

2. 마이크 권한

마이크 권한은 사용자가 낭독 확인 기능을 실행할 때만 사용합니다. Android 설정에서 언제든지 권한을 철회할 수 있습니다. 권한을 철회해도 본문 열람과 저장된 진도 확인은 가능하지만 음성 낭독 확인은 사용할 수 없습니다.

3. 보유 기간과 파기

기기 안의 통독 기록, 설정 및 사용자가 넣은 번역본은 사용자가 해당 정보를 지우거나 앱 데이터를 삭제하거나 앱을 삭제할 때까지 보관됩니다. 원본 음성은 인식에 필요한 동안 메모리에서만 처리한 뒤 즉시 폐기하며 파일로 보관하지 않습니다.

앱 데이터 또는 앱을 삭제하면 기기 안의 자료는 삭제됩니다. 다만 사용자가 별도로 만든 .speechble 백업 파일은 자동으로 삭제되지 않으므로 저장한 위치에서 직접 삭제해야 합니다.

4. 백업 파일

사용자가 직접 백업을 실행하면 통독 회차, 장·절 진도, 낭독 시간, 이어 읽기 기록, 동의 이력, 선택한 설정과 사용자가 넣은 번역본의 본문이 .speechble 파일에 포함될 수 있습니다. 원본 음성과 전체 음성 인식 문장은 포함되지 않습니다.

.speechble 파일은 암호화되지 않은 휴대용 백업 파일입니다. 저장 위치와 공유 대상을 신중하게 선택해 주세요. 사용자가 Google Drive, 메신저 등 외부 저장소나 앱을 직접 선택해 저장·공유한 경우에는 해당 서비스의 개인정보처리방침과 보안 정책이 적용됩니다.

5. 제3자 제공·처리 위탁·국외 이전

현재 앱은 개인정보를 제3자에게 제공하지 않고, 개인정보 처리 업무를 외부 업체에 위탁하지 않으며, 개인정보를 국외로 이전하지 않습니다.

6. 이용자의 권리와 행사 방법

사용자는 앱에서 진도를 확인하거나 지울 수 있고, Android 설정에서 앱 데이터 전체를 삭제하거나 마이크 권한을 철회할 수 있습니다. 처리자는 기기 안에만 있는 자료에 원격으로 접근하거나 대신 복구할 수 없습니다.
